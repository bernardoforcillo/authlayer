---
title: "Client credentials"
description: "A confidential client bound to a service account, guarded like an API key: the cap within the account's role, the client within the administrator's standing, and re-checked at every mint."
---

The client-credentials grant (RFC 6749 §4.4) is the machine-to-machine one: the
client authenticates with its secret and receives an access token whose
subject is the **service account** it is bound to. There is no user, no
consent and no refresh token — §4.4.3 says a refresh token should not be
issued, and none is.

{/* verify:import */}
```go
import (
	"context"
	"errors"
	"fmt"
	"time"

	"github.com/bernardoforcillo/authlayer/access"
	"github.com/bernardoforcillo/authlayer/apikey"
	"github.com/bernardoforcillo/authlayer/oauth"
	"github.com/bernardoforcillo/authlayer/org"
	"github.com/bernardoforcillo/authlayer/scope"
	"github.com/bernardoforcillo/authlayer/store/memory"
	"github.com/bernardoforcillo/authlayer/token"
)
```

{/* verify:main */}
```go
svc := org.New(org.NewAccess(map[string][]access.Action{
	"project": {"read", "deploy", "delete"},
}), memory.New[org.Organization, org.Member]())
keyStore := memory.NewAPIKeyStore()
keys := apikey.New(svc.Service, keyStore)
signer, _ := token.HS256([]byte("a-32-byte-secret-for-the-example!"))
now := time.Date(2026, 9, 4, 12, 0, 0, 0, time.UTC)
as := oauth.New(memory.NewOAuthStore(), svc.Service, signer,
	oauth.WithIssuer("https://auth.example"),
	oauth.WithClock(func() time.Time { return now }),
	oauth.WithServiceAccounts(keyStore))

ctx := org.WithSubject(context.Background(), "alice")
acme, _ := svc.CreateOrganization(ctx, "Acme", "acme")
owner := org.WithOrg(ctx, acme.ID)
_, _ = svc.AddMember(owner, "bob", org.RoleAdmin)
bob := org.WithOrg(org.WithSubject(context.Background(), "bob"), acme.ID)
_, _ = svc.CreateRole(owner, "deployer", "Deployer", map[string][]access.Action{
	"project": {"read", "deploy"},
})
sa, _ := keys.CreateServiceAccount(owner, "ci", "", "deployer")
```

## Minting a client

`CreateClient` needs `service_account:update` — the same grant as minting an
API key, because a client **is** a credential of the account. The secret comes
back exactly once; only its sha256 is stored.

{/* verify:main */}
```go
cc, secret, err := as.CreateClient(bob, oauth.ClientSpec{
	Name:             "ci bot",
	GrantTypes:       []string{oauth.GrantClientCredentials},
	ServiceAccountID: sa.ID,
	Scopes:           []string{"deploy"}, // what it may request; empty = anything the server knows
	Permissions:      map[string][]access.Action{"project": {"deploy"}},
})
fmt.Println("minted:", err, len(secret), cc.SecretHash == token.HashOpaque(secret), string(cc.Permissions))
```

```
minted: <nil> 43 true project:deploy
```

<Note>
**Why sha256 and not bcrypt.** The secret is 32 bytes of `crypto/rand`. bcrypt
exists to slow a guess at a *low-entropy* password; a 256-bit random string
cannot be guessed at any speed, and every token request would pay bcrypt's
cost. The comparison is constant-time.
</Note>

## The two guards

A client is a grant of the account's standing to whoever holds the secret, so
minting one is guarded exactly as `apikey.CreateKey` guards a key:

{/* verify:main */}
```go
// 1. The cap must sit within the account's role: deployer has no delete.
_, _, err = as.CreateClient(bob, oauth.ClientSpec{
	Name: "too much", GrantTypes: []string{oauth.GrantClientCredentials}, ServiceAccountID: sa.ID,
	Permissions: map[string][]access.Action{"project": {"delete"}},
})
fmt.Println("cap above the role:", errors.Is(err, scope.ErrPrivilegeEscalation))

// 2. The client's whole power must sit within the ACTOR's capped standing:
//    bob, acting through a read-only key, cannot mint the deployer's role.
readOnly, _ := svc.Access().Permission(map[string][]access.Action{
	"project": {"read"}, scope.ResourceServiceAccount: {scope.ActionUpdate},
})
capped := scope.WithPermissionCap(bob, readOnly)
_, _, err = as.CreateClient(capped, oauth.ClientSpec{
	Name: "whole role", GrantTypes: []string{oauth.GrantClientCredentials}, ServiceAccountID: sa.ID,
})
fmt.Println("client above the actor:", errors.Is(err, scope.ErrPrivilegeEscalation))

// An empty cap is refused rather than stored as "no cap".
_, _, err = as.CreateClient(bob, oauth.ClientSpec{
	Name: "nothing", GrantTypes: []string{oauth.GrantClientCredentials}, ServiceAccountID: sa.ID,
	Permissions: map[string][]access.Action{},
})
fmt.Println("empty cap:", errors.Is(err, oauth.ErrEmptyPermissions), errors.Is(err, apikey.ErrEmptyPermissions))
```

```
cap above the role: true
client above the actor: true
empty cap: true true
```

## Minting a token

`ClientCredentials(ctx, clientID, secret, scope)` reads no subject: the client
is the credential. The token carries `sub` = the account, `client_id`, the
scope, the container, and the cap — signed.

{/* verify:main */}
```go
tokens, err := as.ClientCredentials(context.Background(), cc.ID, secret, "deploy")
fmt.Println("tokens:", err, tokens.TokenType, tokens.Scope, tokens.RefreshToken == "")

claims, _ := signer.Parse(tokens.AccessToken)
fmt.Println("claims:", claims.Subject == sa.ID, claims.Issuer, claims.ClientID == cc.ID, claims.Actor == nil,
	claims.Extra[oauth.ExtraKind], claims.Extra[oauth.ExtraContainerID] == acme.ID)

p, _ := as.Authenticate(context.Background(), tokens.AccessToken)
bot := apikey.WithPrincipal(context.Background(), p)
read, _ := svc.Can(bot, "project", "read")
deploy, _ := svc.Can(bot, "project", "deploy")
fmt.Println("role ∩ cap:", read, deploy)
```

```
tokens: <nil> Bearer deploy true
claims: true https://auth.example true true service_account true
role ∩ cap: false true
```

`project:read` is in the deployer role and **not** in the cap, so the client
cannot read: the cap can only remove. The [Principal](/service-accounts/authenticating)
is `KindServiceAccount`, with `ClientID` set and `KeyID` empty.

## What is refused

| Condition | Error |
|---|---|
| unknown client id, wrong or missing secret, a secret from a public client | `ErrInvalidClient` |
| the client's `DisabledAt` is set — reported only after the secret verified | `ErrClientDisabled` |
| the client does not hold `client_credentials` | `ErrUnauthorizedClient` |
| a scope outside the client's list or the [scope map](/agents/delegation#the-scope-map) | `ErrInvalidScope` |
| the account is no longer a member; with `WithServiceAccounts`, missing or disabled | `ErrInvalidClient` **wrapping** `scope.ErrNotMember`, `apikey.ErrServiceAccountNotFound` or `apikey.ErrServiceAccountDisabled` |
| the cap no longer sits within the account's role | `scope.ErrPrivilegeEscalation` |

{/* verify:main */}
```go
_, err = as.ClientCredentials(context.Background(), cc.ID, "wrong", "")
fmt.Println("wrong secret:", errors.Is(err, oauth.ErrInvalidClient))

_ = keys.DisableServiceAccount(owner, sa.ID)
_, err = as.ClientCredentials(context.Background(), cc.ID, secret, "")
fmt.Println("disabled account:", errors.Is(err, oauth.ErrInvalidClient), errors.Is(err, apikey.ErrServiceAccountDisabled))
_ = keys.EnableServiceAccount(owner, sa.ID)

// The mint re-checks the cap against the account's CURRENT role.
_ = keys.ChangeServiceAccountRole(owner, sa.ID, org.RoleMember)
_, err = as.ClientCredentials(context.Background(), cc.ID, secret, "")
fmt.Println("role lowered under the cap:", errors.Is(err, scope.ErrPrivilegeEscalation))
```

```
wrong secret: true
disabled account: true true
role lowered under the cap: true
```

<Warning>
**The mint re-checks the cap, and the check re-checks the role.** A token
already issued carries the cap it was minted with, but the engine intersects
that cap with the account's role at **every** `Can` — so lowering the role
lowers every live token too, and the next mint is refused outright rather
than issued with a claim the account no longer holds.
</Warning>

## Disabling and deleting

`DisableClient` refuses every token endpoint with `ErrClientDisabled` and makes
`Authenticate` refuse the client's tokens at once (unless verification is
[offline](/agents/introspection-and-revocation#offline-verification)).
`EnableClient` restores it exactly. `RotateClientSecret` returns a new secret
once and stops the old one the instant the row is written. `DeleteClient`
removes the client and, atomically, everything of it.

{/* verify:main */}
```go
_ = keys.ChangeServiceAccountRole(owner, sa.ID, "deployer")
tokens, _ = as.ClientCredentials(context.Background(), cc.ID, secret, "")
_ = as.DisableClient(bob, cc.ID)
_, err = as.Authenticate(context.Background(), tokens.AccessToken)
fmt.Println("disabled client's token:", errors.Is(err, oauth.ErrInvalidToken), errors.Is(err, oauth.ErrClientDisabled))
_ = as.EnableClient(bob, cc.ID)
rotated, _ := as.RotateClientSecret(bob, cc.ID)
_, err = as.ClientCredentials(context.Background(), cc.ID, secret, "")
fmt.Println("old secret after rotation:", errors.Is(err, oauth.ErrInvalidClient), rotated != secret)
```

```
disabled client's token: true true
old secret after rotation: true true
```
